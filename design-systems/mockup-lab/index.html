Mockup Lab

A coded mockup layer for portfolio and case-study presentation. Device shells, packaging forms, and a sticky-stacking case deck — all built on the 06-solvetrend-signature token contract, so swapping one tokens.css import re-skins every mockup on the page.

Four industries represented. Bright pastel project palette, deliberately scoped outside the house tokens: each project owns a colour, the card gets tinted, the work never does.

01 — Palette

Eight pastels, three tones each

Tint for the card, deep for borders and strips, ink for type. Every ink pairing clears 7:1 on its tint — well past WCAG AA, matching the ratios recorded in each system README.

03 — Case deck

Four industries, one sticky stack

Ascending top plus ascending z-index on position:sticky. Zero JavaScript. Scrolling deals the cards into a deck, so a prospect sees one project at a time instead of skimming a grid. Collapses to a plain list at 900px and under prefers-reduced-motion.
